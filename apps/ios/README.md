## 0.5.1：Claude 菜单不再闪退，输入框说明原因，答案里的文件能打开（10-27 发 TestFlight 构建 7，待真机验）

用户 10-27 在 0.5.0 上反馈（有的经推送会话转来）：在电脑没打开的 Claude 对话里点模型按钮，应用闪退；电脑没打开对话时发送键灰着，也不说为什么；Claude 的模型显示成 “claude-opus-…”；Codex 答案底部有一串看不懂的字；答案里的文件下载不了；选的照片只显示文件名。0.5.1 从合进 main 的 `ios-native` 构建，带着 0.5.0 的遥应通知。

做了什么：

- **闪退**：Claude 的推理强度不是一条滑块（比如电脑给的是“低、中、高……”六档名字）时，模型菜单把“没有滑块”当成了一条步长为 0 的滑块，一画就崩（崩溃记录由推送会话读出）。改好了，画之前还会再查一次步长。代码里同样的写法另有五处，一并改了：其中一处会让有计划的 Codex 对话里每条消息都画成空的计划卡。
- **电脑没打开这个对话时**：输入框上方写出电脑给的原因，旁边有“电脑上打开”；Codex 的模型按钮变成“电脑上打开”，点了电脑就打开这个对话，按钮随即变回模型名，可以发。Claude 对话不用先打开也能发（电脑自己切过去，和网页一样），模型按钮显示记下的名字和强度，例如“Opus 5.5 · 高”。
- **答案里的文件**：答案链接到电脑上的文件（以前写“（链接未开放）”）时，点它进这个文件的页面，可以用快速查看看、保存到“文件”、分享。电脑只列出答案里提到的文件，没列出的会说明打不开。
- **Codex 的注记**：Codex 新加在答案底部的 `<oai-mem-citation>…` 记忆引用不再显示，复制和分享也不带；它新的文件标记 `:codex-file-citation{…}` 显示成文件链接。
- **照片**：输入框里选好的照片显示成小图，点它全屏看。

还要电脑端改，已交给 Windows dev.22 会话：同一段答案出现两次（电脑读 Codex 记录时把同一条答案读了两遍，网页和安卓也一样）；Codex 新写法标出的文件，电脑要先把它列进对话文件，手机才能下载；发出去的消息里显示图片（电脑现在只给“[图片]”三个字）。安卓那边的同样问题交给了安卓会话。

检查情况：本机 `TeleplyCore` 138 项全部通过（合并后的代码）；这次按用户的意思没跑云端截图，省下 Codemagic 分钟，新的“电脑上打开”、原因提示、照片小图都还没在模拟器上看过，第一次就在真机上看。

1. **闪退**：在电脑没打开的 Claude 对话里点模型按钮，菜单正常打开，不再闪退。

### 留给你在真机上验（0.1.0）

1. TestFlight 里装“遥应”0.1.0（1）。桌面图标是 Teleply 标志，名字“遥应”。
2. 打开：白底上标志和“Teleply”居中，往上浮现；下面一行“版本 0.1.0（1）”，再下面“服务 ”加服务器版本号（例如 0.27.0-dev.16）。出现服务版本，说明证书和网络设置在真机上没问题。
3. 系统切到深色模式再打开：黑底、标志和名字变白。
4. 开飞行模式后从后台划掉再打开：应写“连不上服务器，请检查网络后重试。”和“重试”；关掉飞行模式点“重试”，应出现服务版本。
5. 设置 → 显示与亮度 → 文字大小调到最大：字跟着变大，不被截断。

本轮学到的（以后照做）：
- Xcode 27.1 的编译器编不了“异步写法”的 Objective-C 回调方法（崩溃，不是报错）。系统回调一律用传统的回调写法；`ci-testflight.sh` 发现“nearly matches optional requirement”提醒就让构建失败，免得回调悄悄不生效。
- XcodeGen 的应用预设会在目标一级填设置，盖掉工程一级的同名设置；只对某个目标生效的设置写在目标里。上传前的 Info.plist 检查要留着。
- Codemagic 接口：构建产物字段叫 `artefacts`；脚本步骤的日志挂在 `subactions` 上；证书、描述文件、密钥名没有接口可读，只能在构建开始时核对。
