# Teleply Android 原生预览（0.9 照网页账号页和侧栏、开发者选项）

## 0.9 改动（2026-10-25）

依据两份原生规范0.7（安卓和iOS一起改）。用户看过 0.8 后说核心页面可以了，但和网页其余界面还有相当的不同：打开应用应当是 Teleply 标志加电脑列表，"不用自己输入服务器"；侧栏要像网页那样有来源标志和文件夹图标；图标和按钮再完善一下。之后又要求登录页右上角只留设置，测试示例和服务器地址这些"都放到设置的开发者选项里面"。

- **打开应用**：先显示居中的 Teleply 标志和名字，同时读记着的服务；没记过就用默认服务 `https://8.166.15.235`（和 `mobile/src/settings.mjs`、部署配置一致），不用填。然后照网页账号页：没登录→登录；登录过→上次用的电脑在线就回到那台电脑和对话，只有一台电脑也直接进去，否则到"我的电脑"。服务器连不上时，登录页写原因并给"重试"。代码在 `ReaderViewModel.kt`（`launch`、`restore`）。
- **登录页**（`AccountUi.kt`，照 `relay_account.html/.css/.js`）：标志和名字、大标题"登录"、"邮箱或账号""密码"两栏（浅灰底，聚焦时变白、栏名缩到上方）、黑色"登录"按钮。服务开了邮箱时有"忘记密码？""创建账号"，用浏览器打开网页账号页办理（真实服务现在开着）。右上角只有设置按钮，点了直接进设置。服务地址不再出现在登录页。
- **我的电脑**：标志和名字在左上，每台电脑一行，在线的有"连接"，离线的灰掉；每行 ⋯ 里"重命名""移除"（服务端 `/account/rename`、`/account/revoke`）；标题旁的账号菜单有刷新、设置、退出登录（`/account/logout`，同时清掉手机上的登录凭据）。停在这页时每 15 秒读一次。
- **动效**：账号页各块照网页 `.rise` 依次升起（14dp、6dp 模糊、700 ms，后一块晚 70 ms；模糊要 Android 12 起）。系统关了动画时直接出现。
- **侧栏**（`DrawerUi.kt`，照 `static/sidebar-ui.js`）：Codex、Claude、DeepSeek 前面是各自的标志（Codex 用网页的代码符号；Claude、DeepSeek 的图形来自 Simple Icons，CC0；代码在 `Brand.kt`）；项目前面是圆角文件夹，"其他对话"前面是对话气泡；第一次打开时来源展开、项目收起；箭头转动，各组依次滑入，运行中的圆点有扩散的光圈。新建对话里"项目"一行用同一个文件夹图标。
- **图标**：新增文件夹、对话气泡、眼睛（显示密码）、退出、铅笔、垃圾桶等线条图标，和网页同一套画法（24 视口、1.8 描边；文件夹 1.5）。Teleply 标志只用定稿图形，深色时是白色。
- **设置**：首页只留用户要设的：对话、外观、手机通知、语音输入、账号（我的电脑、退出登录）、关于遥应（版本、检查更新、开源组件），最下面一行"开发者选项"。"读屏与字号"一组去掉（应用自己跟着系统设置走）；"后台会话检查"的说明缩短；开源说明收进"开源组件"。
- **开发者选项**（新页）：服务地址（进"服务地址"页）、服务版本、本地示例、诊断测速、完整版本号和包名。登录页的设置按钮也能进来，所以没登录时一样能换服务、打开示例。诊断测速在网页上放在设置首页，这里收进开发者选项（排查问题用）。
- **服务地址**：连得上才换过去，然后像刚打开应用一样走一遍（在那个服务上登录过就直接到电脑）；连不上就留在这页写明原因，记着的服务不变（以前会先改掉记着的服务，再停在启动画面）。地址和原来一样时，保留上次的电脑和对话。
- **离开本地示例**：以前"返回登录"后还带着示例的状态；现在从头按记着的服务走一遍。示例本来就不改手机记着的服务、电脑和对话，新测试把这一点也查上了。

- **会话状态**：以前 Claude 和 DeepSeek 每 3 秒读一次、每次都带 `fresh=1`，电脑每次都去读 Claude 的窗口（约 1.4 秒，读的时候占着 Claude，发送和菜单都要排队）。现在照网页：Claude 每 5 秒、DeepSeek 每 2.5 秒，不带 `fresh`（电脑可以用 4 秒内读过的）；只有进入对话和做完操作才带；点选项、答题、批准等电脑正在执行时不读。

- **列表**：停在列表页时每 10 秒读一次第一页，从对话回到列表时也读；新的行合并进来，已经翻过的页不动。

## 发布新版本（0.8 起）

1. 改 `app/build.gradle.kts` 的 `versionName`（`0.x.y-nativepreview`），`versionCode` 加一。
2. 在保留调试签名的这台电脑上运行 `./scripts/release.ps1`：跑 JVM 测试，构建 release，输出 `build/TeleplyNative-0.x.y-N.apk`，打印签名证书和 SHA-256。证书必须是 `ae834764…02b1bb13`。
3. 把这个文件附到本仓库的 GitHub Release，文件名不改（预发布也可以）。手机上的应用每天看一次，也可以在设置里点"检查更新"。
4. `debug.keystore` 一旦丢失，原生版和旧版都发不了能覆盖安装的更新，建议另外离线备份一份；不要提交进仓库。

1. **无障碍与输入（T03/T12/T13）**：消息/代码/表格标题具备语义，单选/多选整行可操作且标签明确；重复“复制/移除”动作标明对象；流式正文不逐token播报。保持48dp触摸目标，2倍文字、横屏与短窗口下关键操作可滚动到达；键盘优先返回，菜单/详情其次，草稿不丢。采用系统动效尺度，不增加强制动画。Compose语义检查不能替代TalkBack真人阅读、焦点顺序与中文候选输入验收。
2. **系统分享与外部预览（B01/B12/B16，T08/T10）**：在明确授权的当前文件详情增加系统“分享/用其他应用打开”，以流式下载取得具体文件，写入独立应用私有分享缓存；FileProvider只暴露该子目录，给接收方临时只读content URI，不传Cookie、服务地址或本地路径，不执行HTML脚本。切换身份/会话取消旧结果；只显示“已打开系统选择器”，不虚报分享完成。保存继续走系统文档创建器。过期分享缓存受限清理，分享中的文件不立即删除。
3. **通知与跳转（B01/B11，T11/T12）**：默认关闭，由用户为当前会话开启；Android13+在该动作中请求通知权限，拒绝不影响阅读。采用平台JobScheduler按系统最低周期进行有网络约束的只读状态检查，明确不是实时推送，Doze/省电/强制停止可延迟或停止。只关注一个明确会话，检查前重新核对服务、登录作用域和设备归属；失效或离线不猜测完成。状态变化去重，通知不展示正文/账号/客户标题。点击通知使用本机生成的不可猜测目标标记，经当前账号重新核对后导航，不从Intent接收凭据或任意URL；不执行发送/批准。前台正在阅读同一会话时不重复通知。开机恢复只恢复已启用的系统任务，不承诺后台无限保活。
4. **语音输入（T03/T08/T11）**：仅显式点按后请求RECORD_AUDIO；优先设备具备的本机识别，否则明确系统识别可能联网。无识别服务、拒绝权限、取消、空结果都有说明；结果只加入原会话草稿，绝不自动发送，不覆盖后续新输入，不跨账号/电脑/会话回填。退后台/切换/销毁时取消并销毁识别器，不保留录音文件，不调用服务端语音服务或上传整段音频。真实录音/识别质量需用户配合，固定回调测试只证明状态处理。
5. **窗口、恢复与性能（B09/B11，T02/T04/T11/T13）**：宽窗口提供列表/详情，按可用宽高和字体缩放回退单栏；不按设备名称判断，不因旋转、分屏或宽度变化复制会话/请求。列表有界分页，读取锚点与展开状态尽量保持；优化Markdown重复解析与可见内容渲染，避免流式更新牵动整个历史。验证前后台、进程恢复、旋转/宽窗口与大字。使用固定脱敏长会话记录模拟器设备、数据规模和测量方式；不把debug模拟器的数字或静态截图当成真机帧率承诺。

## 数据与边界

`ReaderViewModel` 用 StateFlow 管理导航、请求代次、身份和恢复；`ChatController` 管理草稿、提交与生命周期订阅，`StreamReducer` 核对每条连接的身份和序号。切换请求会取消协程，并拒绝迟到结果。`RelayApi` 使用 OkHttp 和已锁定的 okhttp-sse；所有电脑业务 URL 均显式绑定 `/d/{deviceId}/`。后台停止订阅，回前台先核对状态和原回执，再取新快照；不重放写请求。

服务地址必须为 HTTPS 根地址；POST Origin 与规范化根地址一致；系统 TLS 验证保持开启；禁用所有自动重定向。只接收安全、HttpOnly、host-only、根路径的 `__Host-ar_account` Cookie，通过 Android Keystore AES-GCM 加密并绑定 origin 保存。密码只用于一次登录，不持久化、不日志输出、不读取旧 WebView Cookie。备份和设备迁移排除应用数据。

DataStore 保存外观、服务配置和恢复 ID，不存密码、正文或对话标题；Room v3 按登录作用域 / 电脑 / 来源 / 会话隔离锚点、草稿和提交快照，并用 interaction_draft 保存附件元数据、引用、回答和创建请求。v1→v2→v3显式迁移保留既有数据；提交快照先落盘，才执行一次 POST。正文历史仅留内存，草稿和提交快照留在禁止备份的应用私有存储。UI 的 TextFieldValue 保留光标和中文组合区，逐字输入不由服务状态回写；仅加载、恢复或提交清空时改变外部文本版本。IME可见时系统返回只收起键盘。

当前 `/account/state` 无稳定账号 ID；登录过期时保留阅读快照。重新登录后，只有原电脑 ID 仍在该账号拥有的设备列表中才恢复原作用域；否则清除旧视图并分配新作用域。进程重启后先验证账号与设备，再读取锚点附近历史。离线电脑和 `409 device_offline` 明确处理。

Markdown 由 CommonMark Java 0.24.0（BSD-2-Clause）解析成原生段落、标题、列表、引用、代码、表格和链接。宽代码/表格局部滚动；复制原始文本；截断消息必须先展开完整内容。HTML 文件在应用内的网页视图里按网页打开（0.7起，用户决定）：脚本和网上资源照常加载，同目录文件只取这个对话列出的；不带应用的 Cookie、没有原生桥、不能读手机文件，点链接用系统浏览器打开。授权当前文件支持文本、图片和PDF原生预览、系统保存；本轮差异只读取来源已完成的变更记录。手机文件先分块读取到应用临时缓存再流式上传，保存分块下载，取消或切换身份终止旧传输；临时上传文件在结束/取消时删除。单图20MB、最多5张/合计50MB、文件上传100MB沿用服务约束；本预览版下载上限100MB，图片/PDF内嵌预览上限20MB（更大文件可保存），文本预览遵守服务1MB上限。AndroidX、Kotlin、OkHttp 采用 Apache-2.0。液态玻璃代码移植自 Kyant0/AndroidLiquidGlass（Backdrop，Apache-2.0），见 `third_party/backdrop/`。

契约依据是实施时当前 `relay_service.py`、`relay_identity.py`、`remote.py`、`chat_history.py`、`activity_records.py` 和 `static/reading-ui.js`，不是旧 `relay_cloud.py`。初始 HEAD 为 `81ae96ae9fa4dcc9b615443b70334b4d79a10cbf`；实施期间主仓库其他任务推进至 `ae3184f243e00c4d8e10d38b526044e043c9bc67`，上述 Python 契约文件未变化。固定样例只复用字段结构，无真实账号、聊天、日志或附件内容。
