# Teleply / 遥应设计语言与交互规范

> 状态：用户确认的产品规范，正在落地；不代表所有旧页面已迁移或真机验收通过。
> 适用：浏览器、Android APK 内网页、登录与账号页、设置、会话、文件预览和差异查看。
> 维护原则：修改组件规则先改共用样式，再改调用页面；不为单个新页面另造按钮风格。

## 1. 视觉方向

以清楚、安静、可操作为目标。阅读内容用稳定实体底色；导航与浮动操作用圆形按钮或胶囊组合；玻璃仅用于有明确前后层级的浮层。借鉴 Cindy 的层级和动作逻辑，保留 Teleply 的布局、品牌、数据边界和现有主题。

参考截图中的“返回圆按钮 + 居中标题 + 右侧胶囊工具组”作为会话及详情页共用结构。禁止详情页突然出现浏览器默认描边矩形按钮；差异页、文件预览等辅助页面与主会话属于同一产品。

## 2. 基础令牌

| 类别 | 规范 |
|---|---|
| 正文字体 | 系统中文无衬线；不引入新的装饰字体 |
| 页面/详情标题 | 16–18px，600 字重；列表主标题保留现有字号层级 |
| 控件文字 | 14px，500 字重 |
| 辅助文字 | 12–13px；不能靠过浅颜色导致不可读 |
| 代码/计时 | 代码使用等宽字体；计时使用等宽数字 |
| 间距 | 4px 基础网格；常用 8、12、16、24px |
| 单个图标按钮 | 44×44 CSS px；小屏也不缩小触摸区域 |
| 图标 | 24×24 viewBox，实际 22px；1.8px 描边；圆端点、圆转角 |
| 卡片圆角 | 16px |
| 菜单/面板圆角 | 24px；已有相邻组件逐步归一 |
| 圆按钮/胶囊 | 999px |
| 焦点 | 2px 主题焦点色，外偏移3px；菜单内部可内描边 |
| 深色 | 页面 #000000，面板 #141414，控件/输入 #1E1E1E，分隔 #333333，正文 #EEEEEE，次要 #A8A8A8，强调 #8AB4FF |

浅色沿用现有白底、浅灰面板和现有强调色。颜色通过语义变量使用，不在新组件中随意写独立灰色。正文对比度目标4.5:1，必要边界与焦点3:1。

## 3. 按钮体系

### 导航图标按钮
圆形轻底色，无明显描边；返回、关闭、更多等使用同一图标系统。每个按钮具备可访问名称，桌面悬停可显示说明。视觉图标22px，触摸区域44px。

### 工具组
多个同级操作放入一个胶囊容器，每个操作仍有独立44px点击区。容器提供底色和轻阴影，内部按钮不重复画圆形边框。主内容标题不被工具组挤成多行。

### 主操作
实心胶囊，主题主操作颜色；同一区域最多一个强主操作。发送、确认等保留语义，不把所有菜单管理操作都涂成亮色。

### 次操作
中性浅底胶囊，通常不描边。整段文字与内边距都可点。普通“返回”不再使用文字小方框。

### 菜单行/列表行
整行可点击，至少44px，建议48px；固定图标列、文本列、尾部状态列。当前值放次要文字，子菜单使用勾选。危险操作单独分组，不能只用颜色说明后果。

### 分段选择
跟随系统/浅色/深色，以及同类互斥选项，使用一个胶囊底板与内部选中块。不逐项画三枚描边按钮。键盘方向键可选，状态使用 aria-checked 或 aria-pressed。

### 状态
禁用使用原生 disabled、降低强调度，不响应点击/触摸/键盘；加载保留原控件尺寸；选中不能仅靠颜色。按下缩放0.97，约100ms；减少动态效果时不缩放。触觉沿用系统可用能力，不声称浏览器在所有平台都能震动。

## 4. 图标与品牌

功能图标使用共用 SVG：24×24 viewBox、1.8px描边、圆线帽与圆连接。不得混用 emoji、不同粗细的图标库和随手绘制的字形符号作为导航按钮。
Teleply Logo只使用定稿资源；深色使用透明底白色图形。Claude、Codex、DeepSeek保留自身品牌图形，不强行套用功能图标描边。
返回用左向折线；更多用三个点；文件夹/设备/搜索/设置在全产品使用同一个图标映射。

## 5. 动效语言

| 效果 | 专业名称 | Teleply参数与行为 |
|---|---|---|
| 从三点位置展开 | Anchored Expansion，锚点展开 | 根据触发按钮与空间选上下方向和变换原点 |
| 轻微pop | Spring-like easing / Overshoot，弹性与过冲 | 220ms；scale .96 → 1.005 → 1；位移约6px |
| 选项稍后跟上 | Follow-through / Overlapping Action，跟随与重叠动作 | 内容与外框错开，文字不加运动模糊 |
| 逐行出现 | Staggered Entrance，交错入场 | 单行140ms，每行延迟15ms，总延迟不超过60ms，位移3px |
| 收起 | Exit transition | 120ms淡出与轻微缩回，不倒序拖延每一行 |
| 内容滚动 | Momentum Scrolling，惯性滚动 | 沿用系统正常滚动，不叠加逐行动画 |
| 越界后回弹 | Rubber-banding，边界阻尼 | 由可用平台滚动行为提供，不为菜单强制仿造 |
| 减少动态效果 | Reduced Motion | 去掉缩放、位移、交错；仅短淡入 |

这些是Teleply自定初值，不是从静态截图提取的Cindy参数。动画不阻塞点击，不对内容刷新反复播放；连续开关不能堆叠浮层。

## 6. 玻璃与层级

菜单底板使用主题半透明填充、约16px背景模糊、轻度饱和度、1px细边和柔和阴影。浅/深分别调色。正文、代码、表格、差异阅读面保持不透明。
背景压暗层与玻璃面板分别管理；不让所有浮层变成同一块灰雾。
不支持 backdrop-filter 或用户减少透明效果时使用实体面板。性能下降优先取消交错与过冲，再简化模糊。禁止每条消息都建立独立模糊层。

安卓浏览器、Android WebView和iPhone Safari均可使用这套网页动效。苹果原生Liquid Glass和UIMenu不能原样搬到安卓；本方案追求一致的层级与反馈，不承诺系统材质逐像素一致，也不强制控制Safari地址栏。

## 7. 页面结构与侧栏

- 侧栏：全局导航，来源/项目/会话；底部账号与电脑、刷新、连接状态、设置。
- 列表三点菜单：分组、排序、状态、来源；显示当前值。
- 会话三点菜单：当前会话操作。
- 设置：外观、关于遥应等；浏览器不出现APK更新。
- 详情页：圆形返回、居中标题、右侧胶囊工具组；长文件名省略，完整路径在详情内容可查看。
- 差异页的换行、布局模式、文件列表进入更多菜单；只有多文件时才显示上一/下一文件，不常驻两个无效按钮。
- 子菜单在窄屏替换本面板，保留返回行；外点/Escape/Android返回关闭最上层，关闭后恢复触发点焦点。

## 8. 活动过程与读秒

每轮活动按稳定轮次标识聚合，最终回复独立。标题区显示状态、可靠时间和修改文件数；细横线划分标题，单层竖线串联活动。线条不代表百分比。
运行时默认当前及最近两项，展开后看全部；手动展开/收起不会被更新覆盖。正常完成默认折叠；问题卡片不藏入过程详情。
工具卡片默认动作、对象、状态；命令、输出、长脚本按需展开。错误必须在外层可见。
只显示源端公开的思考摘要和进度。没有可靠时间则不显示精确读秒；断网不假装继续掌握执行进度。等待时间的排除必须有可恢复的来源证据，不能靠刷新后丢失的临时计时状态。

## 9. 文件差异

“当前文件”与“本轮差异”分开命名。只读接口使用绑定会话/操作的修改引用，不接收任意磁盘路径。
Codex明确完成的文件变更补丁可展示；Claude Edit的成功结果可展示原/新替换片段，明确“片段行号”。Write只有新内容时不推测旧内容。没有证据时不把工作区Git差异说成本轮修改。
手机统一差异，宽屏可左右对照；包含行号和+/-，不只依赖红绿。大文件按修改块加载，二进制沿用文件预览。此轮不提供回滚、编辑、暂存或提交。

## 10. 组件与验收

共用基础令牌与按钮在 static/theme.css；活动/菜单/差异样式在 static/interaction.css；交互在 static/interaction-ui.js。新页面优先使用 tp-icon-button、tp-toolbar、tp-button、tp-menu，不临时写另一套按钮边框。
旧组件迁移以不改变行为为前提；完成迁移前不写“所有页面已统一”。

验收须包含：390px窄屏、横屏、桌面宽屏；深浅主题；键盘/触摸；无模糊回退；减少动态效果；连点与返回；超长标题/长菜单；流式更新与重连；多轮同文件修改；失败操作不能成为已完成差异。截图必须等待动画稳定，再判断材质与透明度。
自动化和模拟器证据与iPhone/Android真机结果分开。构建、公开发布、云端部署、本机安装和手机安装分别记录。
